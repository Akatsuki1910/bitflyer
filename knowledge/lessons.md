# 教訓ノート

判断や見立てを外したとき、または根拠の誤りに気づいたときの振り返りを記録します。
Claude の見立てタスクが**毎回読み、必要なら書き足します。**

運用のルールは [`playbook.md` の D-01 / D-04](playbook.md#6-判断を評価して直す方法) に従います。

- **状態:** `仮説` → `採用`（playbook に反映）/ `撤回`
- **昇格:** 同じ種類の外れや根拠の誤りが3回以上確認できた、または誤りが結果と無関係に明白
- **撤回:** 仮説に反する事例が続いた
- **消さない。** 撤回した教訓も理由と一緒に残す
- **1回の外れを教訓にしない。** 根拠も確信度も妥当だった外れは「ノイズ」として採点記録に残すだけ

各教訓の書式:

```
### L-000
**状態:** 仮説 / 採用 / 撤回　**記録日:** YYYY-MM-DD　**分類:** 根拠の誤り / くり返し / 入力の不備
**起点:** 何を判断して、何が起きたか（call id や見立ての日付）
**原因:** なぜ外れたか（結果ではなく判断の過程の問題として）
**修正:** 次からどうするか
**確認:** その後、この教訓に合う/反する事例（日付と call id）
```

## 教訓一覧

### L-001

**状態:** 採用　**記録日:** 2026-09-11　**分類:** 根拠の誤り

**起点:** 2026-09-10 と 09-11 の見立てで、2回続けて「Fear & Greed は強欲寄りなのに価格は下げている＝ねじれ」
「ニュースのトーンは強気寄りなのに価格が下げている」を注目点（watchlist）に入れ、どちらに解消するかを見どころにしていた。

**原因:** Fear & Greed は価格に**反応する**指標で、日次の価格を予測する力は確認されていない
（playbook I-01 の出典）。ニュースのトーンは語句の単純カウントで文脈を読んでいない（I-02）。
予測力の無いものと価格のずれは「解消を待つべきねじれ」ではなく、ただの遅れや雑音。

**修正:** Fear & Greed とニュースのトーンは、相場の温度を**記述するだけ**にとどめ、判断の根拠や watchlist にしない。
playbook の I-01 / I-02 に反映済み。

**確認:** —

### L-002

**状態:** 採用　**記録日:** 2026-09-11　**分類:** 入力の不備

**起点:** 2026-09-11 の見立てで「16口座が **9/9朝** の一斉買いから固まったまま」と書いたが、
クリーンアップ後の初回（最初の買い）は **2026-09-10 08:39 JST**。日付が1日ずれていた。

**原因:** `src/brief.py` が Supabase の時刻を UTC のまま出していた（`2026-09-09T23:39Z`）。
これを日本時間の日付として読んだ。判断の過程ではなく、入力の表示の問題。

**修正:** `brief.py` の時刻表示をすべて JST に変更した（仕組みで解決）。見立てで日時を書くときは JST 表記を確かめる。

**確認:** —

### L-003

**状態:** 採用　**記録日:** 2026-09-11　**分類:** 入力の不備

**起点:** 2026-09-11 の見立てで、BAT の価格が「11円のまま」と表示される一方、実勢は -3.18% 動いていた。
見立て自身が「表示は11円のまま」と注記して読み違いは避けていたが、1円未満の変動が見えない状態だった。

**原因:** `brief.py` が価格を円単位に丸めていた。BAT は1枚10円台なので、数%の変動が表示上消える。

**修正:** `brief.py` で1,000円未満の価格は小数2桁まで出すようにした（仕組みで解決）。

### L-004

**状態:** 採用　**記録日:** 2026-09-11　**分類:** 根拠の誤り（の予防）

**起点:** 2026-09-11 の見立てで「ETH は100日線・3か月モメンタム・SMA20/50・SMA50/100・買い持ちの5戦略が
同じタイミングで買い、全部 +0.33% で完全に重なっている」と観察していた。

**修正:** ルール口座の多数決（何口座が買いか）を、Claude の判断の根拠にしない。playbook I-09 に反映済み。
