# 教訓ノート

判断や見立てを外したとき、または根拠の誤りに気づいたときの振り返りを記録します。
Claude の見立てタスクが**毎回読み、必要なら書き足します。**

運用のルールは [`playbook.md` の D-01 / D-04](playbook.md#6-判断を評価して直す方法) に従います。

- **状態:** `仮説` → `採用`（playbook に反映）/ `撤回`
- **昇格:** 同じ種類の外れや根拠の誤りが3回以上確認できた、または誤りが結果と無関係に明白
- **撤回:** 仮説に反する事例が続いた
- **消さない。** 撤回した教訓も理由と一緒に残す
- **1回の外れを教訓にしない。** 根拠も確信度も妥当だった外れは「ノイズ」として採点記録に残すだけ

各教訓の書式:

```
### L-000
**状態:** 仮説 / 採用 / 撤回　**記録日:** YYYY-MM-DD　**分類:** 根拠の誤り / くり返し / 入力の不備
**起点:** 何を判断して、何が起きたか（call id や見立ての日付）
**原因:** なぜ外れたか（結果ではなく判断の過程の問題として）
**修正:** 次からどうするか
**確認:** その後、この教訓に合う/反する事例（日付と call id）
```

### L-005

**状態:** 採用　**記録日:** 2026-09-21　**分類:** 根拠の誤り

**起点:** 2026-09-16 の BTC・ETH の判断（どちらも outlook=down 確信度0.55、どちらも外れ）で、
「20日線を割った」「前日が −2.4%／−2.8%」を下方向の根拠にした。2026-09-15-ETH（outlook=up、外れ）でも
「20日線を回復した」を上方向の根拠にしていた。個々の外れはノイズに分類したが、根拠の作り方が同じ型だったので
過去1年の日足で、この型が本当に効くのかを調べ直した（`src/study.py`、ページの「1年ぶんの答え合わせ」）。

**原因:** 直近365日で、判断に使ってきた11の材料 × 3銘柄 = 33通りを検定すると、
翌日の方向が五分五分と言えないほど偏ったのは **1通りだけ**（偶然でも1.7通りは出る水準）。
個別に見ても、

- 翌日が前日と同じ向きに動いた割合は BTC 51% / ETH 49% / BAT 48%
- 「20日線の上／下にいる」翌日の方向は、どの銘柄も 51〜57%（p=0.16〜0.93）
- 「20日線を割った日」「上抜けた日」は判定できる日数が14〜18日しかなく、何も言えない

つまり移動平均の位置や前日の値動きは、**24時間の方向を当てる材料としては効いていない**。
結果と無関係に「効かない指標に頼った」と言える（playbook D-01 の「根拠の誤り」）。

**修正:** 20日線・100日線との位置関係や直前の値動きを、**24時間の見通し（outlook）の根拠にしない**。
地合いの記述と、position（数週間持つかどうか）の材料としてだけ使う。
方向の根拠がそれしか無いなら outlook=flat で見送る。playbook I-03 と P-08 に反映。

**確認:** 2026-09-21 の検証（365日、33通りの検定）

### L-006

**状態:** 採用　**記録日:** 2026-09-21　**分類:** 根拠の誤り

**起点:** 「24時間の方向を当てて position を動かす」という判断の形そのものを、コスト側から検算した。

**原因:** 的中率 p で当てて平均 m% 動くなら、期待値は (2p−1)×m。往復コストを上回るには
p > 0.5 + コスト/(2m) が要る。直近365日の平均値幅で計算すると:

| 保有 | BTC（往復0.43%） | ETH（往復0.49%） | BAT（往復4%） |
|---|---|---|---|
| 1日 | 63% | 60% | **どんな的中率でも不可能**（平均値幅3.5% < 往復4%） |
| 5日 | 56% | 55% | 77% |
| 20日 | 53% | 52% | 65% |
| 60日 | 51% | 51% | 57% |

24時間の方向の基準率はほぼ50%（P-01）なのに、1日で出入りすると BTC で63%、ETH で60% の的中率が要る。
**この差は判断の巧拙ではなく、コストの構造で決まっている。**

**修正:** position を動かす判断は、24時間ではなく**数週間持つ前提**で書く。
往復コストを上回る見込みを書けないなら動かさない（既に playbook 0章にあるが、必要的中率という形で数値化した）。
**BAT は1日〜数日の値幅では往復コストを取り返せないので、日々の値動きを理由に売買しない。**
playbook P-08 と B-01 に反映。

**確認:** 2026-09-21 の検証（365日）

### L-007

**状態:** 仮説　**記録日:** 2026-09-21　**分類:** 根拠の誤り

**起点:** 2026-09-16 の判断で「Clarity Act（暗号資産市場構造法案）の上院での後退」を3銘柄同時安の理由として挙げ、
下方向の見通しの根拠の一つにした。実際には 9/18 に BTC は24時間で +5.5%、$80,000 を回復した
（Clarity Act は否決されたまま、SEC のトークン化証券の革新免除が材料）。

**原因:** ニュースは**動いた後に**書かれる。直近1年で BTC が大きく動いた10日を調べると、
材料は関税・金利観測・法案・清算連鎖・ETF の資金流出で、いずれも記事になったのは動いた後だった。
さらに 2026-02-06（−13.9%）の翌日は +11.9%、2026-08-20 の急伸は記録的なショート踏み上げを伴っており、
**同じ材料が翌日には逆向きに効く**。「ニュースで説明できた下げ」を続落の根拠にするのは、
事後の説明を事前の予測に使い回していることになる。

**修正:** 相場が動いた理由として報じられた材料を、**その先24時間の方向の根拠にしない**。
材料を使うなら「まだ起きていない、日程の決まった出来事」（議会の採決日、FOMC など）に限る。
記述としては書いてよい。

**確認:** 2026-09-16 の BTC・ETH 判断（外れ）／2026-09-19 の反発（`knowledge/events.json`）
