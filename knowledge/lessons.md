# 教訓ノート

判断や見立てを外したとき、または根拠の誤りに気づいたときの振り返りを記録します。
Claude の見立てタスクが**毎回読み、必要なら書き足します。**

運用のルールは [`playbook.md` の D-01 / D-04](playbook.md#6-判断を評価して直す方法) に従います。

- **状態:** `仮説` → `採用`（playbook に反映）/ `撤回`
- **昇格:** 同じ種類の外れや根拠の誤りが3回以上確認できた、または誤りが結果と無関係に明白
- **撤回:** 仮説に反する事例が続いた
- **消さない。** 撤回した教訓も理由と一緒に残す
- **1回の外れを教訓にしない。** 根拠も確信度も妥当だった外れは「ノイズ」として採点記録に残すだけ

各教訓の書式:

```
### L-000
**状態:** 仮説 / 採用 / 撤回　**記録日:** YYYY-MM-DD　**分類:** 根拠の誤り / くり返し / 入力の不備
**起点:** 何を判断して、何が起きたか（call id や見立ての日付）
**原因:** なぜ外れたか（結果ではなく判断の過程の問題として）
**修正:** 次からどうするか
**確認:** その後、この教訓に合う/反する事例（日付と call id）
```

### L-005

**状態:** 採用　**記録日:** 2026-09-21　**分類:** 根拠の誤り

**起点:** 2026-09-16 の BTC・ETH の判断（どちらも outlook=down 確信度0.55、どちらも外れ）で、
「20日線を割った」「前日が −2.4%／−2.8%」を下方向の根拠にした。2026-09-15-ETH（outlook=up、外れ）でも
「20日線を回復した」を上方向の根拠にしていた。個々の外れはノイズに分類したが、根拠の作り方が同じ型だったので
過去1年の日足で、この型が本当に効くのかを調べ直した（`src/study.py`、ページの「1年ぶんの答え合わせ」）。

**原因:** 直近365日で、判断に使ってきた11の材料 × 3銘柄 = 33通りを検定すると、
翌日の方向が五分五分と言えないほど偏ったのは **1通りだけ**（偶然でも1.7通りは出る水準）。
個別に見ても、

- 翌日が前日と同じ向きに動いた割合は BTC 51% / ETH 49% / BAT 48%
- 「20日線の上／下にいる」翌日の方向は、どの銘柄も 51〜57%（p=0.16〜0.93）
- 「20日線を割った日」「上抜けた日」は判定できる日数が14〜18日しかなく、何も言えない

つまり移動平均の位置や前日の値動きは、**24時間の方向を当てる材料としては効いていない**。
結果と無関係に「効かない指標に頼った」と言える（playbook D-01 の「根拠の誤り」）。

**修正:** 20日線・100日線との位置関係や直前の値動きを、**24時間の見通し（outlook）の根拠にしない**。
地合いの記述と、position（数週間持つかどうか）の材料としてだけ使う。
方向の根拠がそれしか無いなら outlook=flat で見送る。playbook I-03 と P-08 に反映。

**確認:** 2026-09-21 の検証（365日、33通りの検定）。
同日、2018年以降の日足で調べ直した（`src/research.py`）。前日の逆に動く傾向（翌日反転）は確かにあったが、
BTC の自己相関は前半（2018〜22）−0.072 → 後半（2023〜）−0.034、ETH は −0.079 → −0.022 と弱まっている。
移動平均・モメンタム・資金調達率・Fear & Greed・米株・曜日・FOMC を全部入れたモデルで翌日の方向を当てると、
前半 54.6% → 後半 51.1%（BTC。「いつも上」は 51.6%）。**方向については、長い期間で見てもこの教訓は変わらない**

### L-006

**状態:** 採用　**記録日:** 2026-09-21　**分類:** 根拠の誤り

**起点:** 「24時間の方向を当てて position を動かす」という判断の形そのものを、コスト側から検算した。

**原因:** 的中率 p で当てて平均 m% 動くなら、期待値は (2p−1)×m。往復コストを上回るには
p > 0.5 + コスト/(2m) が要る。直近365日の平均値幅で計算すると:

| 保有 | BTC（往復0.43%） | ETH（往復0.49%） | BAT（往復4%） |
|---|---|---|---|
| 1日 | 63% | 60% | **どんな的中率でも不可能**（平均値幅3.5% < 往復4%） |
| 5日 | 56% | 55% | 77% |
| 20日 | 53% | 52% | 65% |
| 60日 | 51% | 51% | 57% |

24時間の方向の基準率はほぼ50%（P-01）なのに、1日で出入りすると BTC で63%、ETH で60% の的中率が要る。
**この差は判断の巧拙ではなく、コストの構造で決まっている。**

**修正:** position を動かす判断は、24時間ではなく**数週間持つ前提**で書く。
往復コストを上回る見込みを書けないなら動かさない（既に playbook 0章にあるが、必要的中率という形で数値化した）。
**BAT は1日〜数日の値幅では往復コストを取り返せないので、日々の値動きを理由に売買しない。**
playbook P-08 と B-01 に反映。

**確認:** 2026-09-21 の検証（365日）

### L-007

**状態:** 仮説　**記録日:** 2026-09-21　**分類:** 根拠の誤り

**起点:** 2026-09-16 の判断で「Clarity Act（暗号資産市場構造法案）の上院での後退」を3銘柄同時安の理由として挙げ、

**原因:** ニュースは**動いた後に**書かれる。直近1年で BTC が大きく動いた10日を調べると、
材料は関税・金利観測・法案・清算連鎖・ETF の資金流出で、いずれも記事になったのは動いた後だった。
さらに 2026-02-06（−13.9%）の翌日は +11.9%、2026-08-20 の急伸は記録的なショート踏み上げを伴っており、
**同じ材料が翌日には逆向きに効く**。「ニュースで説明できた下げ」を続落の根拠にするのは、
事後の説明を事前の予測に使い回していることになる。

**修正:** 相場が動いた理由として報じられた材料を、**その先24時間の方向の根拠にしない**。
材料を使うなら「まだ起きていない、日程の決まった出来事」（議会の採決日、FOMC など）に限る。
記述としては書いてよい。

**確認:** 2026-09-16 の BTC・ETH 判断（外れ）／2026-09-19 の反発（`knowledge/events.json`）。
追記（2026-09-21）: **2026-09-16 は FOMC の決定日**で、判断の採点期間（09/16 09:18 → 09/17 09:31 JST）の中に
発表（09/17 03:00 JST）があった。判断のときにこれを見ていなかった。FOMC の発表から24時間の BTC の値幅は、
2018年以降の76回で中央値 前半3.0%・後半1.8%（普段は1.4%）と広がる。一方、方向は偶然と区別できない（L-008）。
日程の決まった出来事は「値幅が広がる」材料としては事前に想定できた。「どちらに動くか」の材料にはならない

### L-008

**状態:** 採用　**記録日:** 2026-09-21　**分類:** 根拠の誤り（の予防）

**起点:** 「翌日の方向は当てられない」（L-005）を受けて、何なら当てられるのかを2018年以降の日足・1時間足で調べた（`src/research.py`）。

**原因:** 値動きの**大きさ**は、前半（2018〜22）と後半（2023〜）のどちらでも予測できた。

- 土曜（UTC）の値幅は平日の 62%（前半）・37%（後半）
- FOMC の発表から24時間の値幅は中央値 前半3.0%・後半1.8%（普段1.4%）
- 直近の値幅・週末・FOMC から前半で作った予測で後半の日を5つに分けると、BTC の実際の平均値幅は
  最も小さい組 0.84%（±0.5%以内に収まった日が50%）〜 最も大きい組 2.31%（同13%）

これまでの判断は値幅の見通しを持たずに書いていた。値幅が小さいと見込める日に up/down を言っても、
半分は「判定なし」になり、ポジションを動かしてもコストを取り返せない。

- 見立ての watchlist に、日程の決まった出来事と値幅の見通しを入れてよい

playbook P-09 に反映。

### L-009

**状態:** 採用　**記録日:** 2026-09-21　**分類:** 根拠の誤り

**起点:** Claude の BTC 口座は 09/12 から一度も持たず（+0.00%）、同期間の買い持ちは +6.47%。
ETH は 09/15 に買って 09/16 に手放した（−3.90%、買い持ちは +4.80%）。
どの判断も、position を**24時間の見通し**（20日線割れ、前日の下げ、ニュース）で決めていた。
一方、BTC は 2026-08-19 から、ETH は 2026-08-13 から100日線の上にいた。

**原因:** 2018年以降の検証で、方向について前半・後半の両方で再現したのは**数週間単位のトレンド**だけだった。

- 過去30日が上げのとき、次の30日のリターンは下げのときより BTC 前半 +6.9pt・後半 +0.9pt、ETH +6.6pt・+2.8pt 高い
- 「100日線の上なら持つ」を週1回だけ判定すると（往復コスト込み）、BTC の年率は 2018-20 +83%（買い持ち +29%）、
  2021-22 +8%（同 −25%）、2025-26 +7%（同 −8%）。最大下落は4期間中3期間で買い持ちより浅い
- 移動平均の日数を30〜200日で変えても、BTC・ETH では最大下落が浅くなった期間が4期間中3〜4期間。1つのパラメータの当たりではない
- ただし強い上昇相場（2023-24）では、BTC で年率 +72%（買い持ち +137%）と大きく取り逃がす
- BAT はどのトレンドのルールでも往復4%に負ける（前半は順張りが効いたが、後半は逆向き）

position を24時間の見通しで決めたのは、効く時間軸を取り違えていた。結果と無関係に誤りと言える。

**修正:** BTC・ETH の position は、**数週間のトレンド（100日線など長めの移動平均との位置）を既定**にして決める。
上にいる間は、24時間の見通しが down でも position=long を既定にする。下にいる間は flat を既定にする。
既定から外すなら、その理由と往復コストを上回る見込みを reasoning に書く。
判定は頻繁に変えない（週1回程度。毎日判定すると売買回数が約3倍になる）。
**BAT は既定を flat のままにする**（B-01, P-08）。
トレンドに従うのは下落の傷を浅くするためで、強い上昇相場では買い持ちに負けることを前提にする。
playbook P-05 と 0章 に反映。

**確認:** 2026-09-21 の検証（2018〜2026年、4期間 × 移動平均5種類）

### L-011

**状態:** 採用　**記録日:** 2026-09-21　**分類:** 根拠の誤り（の予防）

**起点:** 2018〜2022年のデータで材料を全部入れて翌日の方向を予測すると、的中率は BTC 54.6%、
予測の強い上位20%の日だけなら 64.0% に見えた。同じモデルを2023年以降に当てると 51.1%（強い日だけ 52.8%）で、
「いつも上」の 51.6% と変わらなかった。ETH も 55.9% → 49.9%。

**原因:** 材料を増やすほど、たまたま過去に合った組み合わせを拾う。
学習に使った期間の成績は、実力を大きく上回って見える。

**修正:** 「傾向がある」と言う前に、**見つけた期間と別の期間で同じ向きに出るか**を確かめる。
見立てで過去の傾向を引くときも、1つの期間だけの数字は使わない。playbook D-05 に反映。

**確認:** 2026-09-21 の検証
